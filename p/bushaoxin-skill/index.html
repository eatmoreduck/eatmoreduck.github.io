刷了三天AI短剧，我一怒之下做了个全网最癫的不烧心skill

刷了三天AI短剧，全网只记住一句台词。我把这套「规矩体」做成了 Claude skill——bushaoxin 不烧心文学生成器：写文案、做评价、回怼样样行，喊一句「太烧了」它还能自动降火。MIT 开源，一句话安装。

凌晨两点四十七分。

手机屏幕冷白的光打在脸上。

手指机械地往上一滑，屏幕里又是一个胡子拉碴的中年男人，系着油腻的粗布围裙，单手扶着案板，眼神笃定地看着镜头，语气慢得像在数米粒：

“面贵是贵了点，但吃了不烧心。”

再滑一次，还是他。这次换成了卖盒饭，手里的菜勺顿在半空：“宁可少挣点，也不能坏了规矩。”

再滑一次，他甚至改行卖上了软件激活码，依然面不改色：“不怕亏钱吗？怕，更怕账本不清。”

整整三天，我的信息流被这个“良心掌柜”彻底包圆了。闭上眼，耳朵里全是他在敲算盘；睁开眼，天花板上仿佛都悬着五个大字——《规矩不能坏》。

到第四天，我的精神状态终于彻底失常了。

中午十二点十五分，点外卖看到一份28块钱的猪脚饭，心里冷不丁冒出一句：“怕人嫌贵？怕。更怕卤汁不是当天熬的。”

下午两点半开需求评审会，产品经理拍着桌子问“这个功能明天能不能上线”，我嘴皮子一抽，差点脱口而出：“不好意思，一次接不了这么多单。”

晚上回家辅导孩子写作业，看着满桌子的练习册，我甚至想语重心长地拍拍他的肩膀：“剩下怎么办？要完成，人不能没良心。明天怎么办？先做。”

我疯了。

但凡你最近刷过短视频，你大概率也跟我一样，在被这套“规矩体”连环轰炸的边缘疯狂试探。

22万部短剧，全网只记住了一句台词#

这个在全网病毒式蔓延的梗，起源于2026年9月底。

红果短剧等平台上，突然井喷了海量由AI批量生成的市井短剧。这些短剧就像同一个模具里倒出来的塑料小人：主角永远是在街角摆摊三十年的“良心掌柜”，卖包子、卖盒饭、卖猪脚饭，后来甚至演化出卖卡密的小老板。

剧情永远是同一个模板：良心掌柜坚持用新鲜材料、账目分明，哪怕价格贵一点也绝不妥协；隔壁黑心同行大搞科技与狠活和价格战；掌柜咬牙苦撑，最后顾客吃坏肚子认清真相，纷纷回流，良心大获全胜。

因为是AI流水线批量跑出来的剧本，编剧连台词都懒得换，改个商品名就敢发一部。

结果，这些高度同质化的流水线台词，在抖音上硬生生被冲出了破13亿播放的超级话题。

一句“贵是贵了点”，后面必定有人接着对暗号：“但用了不烧心”。

网友们瞬间把这套台词解构成了席卷全网的“万物皆可不烧心”。写代码、谈恋爱、职场对线、健身打卡，任何场景套上规矩体，荒诞感和喜剧效果立刻拉满。小学生不想写作业，会一脸沉痛地对妈妈说：“不好意思，一次接不了这么多单。”

央媒专门下场点名：二十二万部流水线短剧，观众唯一记住的竟然只有同一句话。这是对粗制滥造AI内容的绝妙讽刺。

在这个到处充斥着降本增效、以次充好、互相糊弄的时代，大家疯狂转发的背后，本质上并不是多喜欢粗糙的AI短剧，而是借着这个荒诞的壳子，宣泄打工人内心深处对“靠谱、不坑人、有底线”的极度渴望。

既然人人都在玩梗，既然这股风气怎么躲都躲不掉——

那为什么不把它做进终端里，让AI亲自下场当掌柜？

一怒之下，我手搓了一个不烧心skill#

折腾了一个晚上，我把这套台词体系封装成了一个专给 Claude Code / Agent Skills 使用的开源玩梗工具——bushaoxin（不烧心文学生成器）。

开源协议直接给的 MIT，完全免费，纯粹整活。

这个 skill 的核心人设极其纯粹：让 AI 扮演那位在街角做了三十年小买卖的“良心掌柜”。

不管你让它卖什么——卖面条、卖卡密、卖网课、卖代码，甚至卖真心，掌柜的规矩永远只有一套：材料必须是当天进的，账目必须一笔一笔算清楚，宁可少赚点，绝不能坏了规矩。说话慢、短、笃定，哪怕世界毁灭也绝不激动。

在它的人设底层，死死焊接着几条雷打不动的硬规矩： “规矩高于钱——宁可少挣点，也不能坏了规矩”； “只接拿得住的——这么大个单不接吗？不好意思，一次接不了这么多单”； “稳字诀——不是我稳，是不能慌，一慌就容易做错事”； 还有那句终极的“问是好事——怕没人问，不怕人多问”。

任何文案只要丢进去，出来全是一股老陈醋配大骨汤的陈年老铺味。

口说无凭，直接看真实输出。

现场验货：万物皆可规矩体#

装上这个不烧心skill之后，你的 AI 说话画风瞬间突变。

比如，让它给程序员写一条朋友圈：

需求是接了。但只接自己拿得住的。代码贵是贵了点——工时是工时，账是账。规矩不能坏，先做。

这短短两句话发到群里，那种被需求按在地上摩擦却依然保持体面的老程序员风骨，瞬间立住了。

再比如，让它以不烧心文学的口吻评价一门割韭菜的网课：

贵是贵了点。但学完不烧心。账一笔一笔记清楚，谁的问题谁负责。慢慢来，别慌，一慌就容易学岔。

不攻击、不阴阳，语气平淡得像在递一碗温水，但每一个字都在暗中敲打浮躁的心态。

再让它老老实实写个面馆招牌：

面贵是贵了点。 怕人说值不上？怕。更怕汤不是当天吊的。 天天都要吃的东西，讲究的就是个实在。 规矩不能坏。

什么是专业？这就是做了三十年老生意的底气。

杀手级设计：吐槽就是遥控器#

如果只是机械吐出几句台词，那顶多算个模板生成器，根本配不上掌柜的灵魂。

这个 skill 最绝的地方，在于我给它设计的一套动态火候调节系统。

日常使用时，它默认是中火（四五句标准规矩体）。但你也可以随时指定火候：

  • 微火：点到为止，一两句收工，寡淡中透着深沉；
  • 大火：信条连发，六到八句连珠炮轰，浓度直接拉满；
  • 掌柜附体：AI 直接切换人格，不再是文案工具，而是掌柜搬着马扎跟你唠嗑，连续多轮对话打死都不跳出人设。

但最爽的还不是手动选档位，而是升降火反馈机制。

你根本不需要背任何参数命令，你的吐槽就是它的遥控器。

如果你觉得味儿太冲、快被油烟熏晕了，直接在聊天框里冲它喊： “太烧了！” “烧了烧了！” 或者“降降火”。

它不仅会自动把火候降下一档重新输出，还会顶着掌柜的人设轻描淡写地回你一句：

“嫌烧？那我收火。”

不解释、不辩解，神情淡漠地收火重做。要是你连喊两次“太烧了”，系统会自动判定你快被烤焦了，瞬间直落微火。

反过来，如果你觉得文案不过瘾，回一句“淡了”、“没味儿”或者“不得劲”，掌柜立刻加柴添火，下一秒就是六到八句连珠炮的信条轰炸。

这种被短剧掌柜拿捏得死死的人性交互，才是这个 skill 最上头的精髓所在。

一句话安装，即插即用#

整个工具没有任何冗长复杂的配置步骤。

如果你在用 Claude Code，只需要复制下面这行指令，原样丢给它即可：

帮我安装这个 skill：https://github.com/eatmoreduck/bushaoxin

Claude Code 会自动把仓库拉取下来并完成注册。

如果你习惯用网页版，打开 claude.ai 的 Settings → Capabilities → Skills 直接上传即可；同样，它也原生兼容 Claude API 和各种 Agent SDK。

规矩不能坏，先做#

从流水线短剧里提炼出来的荒诞台词，最后变成了开发者终端里一个能让人会心一笑的玩具。

技术是新的，但人们对真诚、靠谱、踏实的渴望，从来都是旧的。

明天怎么办？先做。
